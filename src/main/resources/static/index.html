cobweb2026 인증 API 테스트

현재 상태

accessToken 없음 (로그인하지 않음)

이메일 인증 (회원가입용)

회원가입 전에 먼저 코드를 발송받아 인증해야 합니다. (유효시간 5분)

1) 인증 코드 발송

2) 코드 확인

소셜 로그인

클릭하면 해당 제공자 로그인 화면으로 이동하고, 완료되면 이 페이지로 돌아와 자동 로그인됩니다.

회원가입 (/api/auth/signup)

위에서 인증을 마친 이메일이어야 가입이 됩니다.

로그인 (/api/auth/login)

토큰 재발급 / 로그아웃

재발급은 로그인 시 서버가 심어준 refreshToken 쿠키(httpOnly)를 그대로 사용합니다.

비밀번호 재설정

1) 재설정 코드 발송

2) 코드 확인 → resetToken 발급

3) 새 비밀번호로 변경
