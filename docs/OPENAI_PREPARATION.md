# OpenAI 서버 연결 준비

현재는 **준비만 완료한 상태**입니다. OpenAI SDK·HTTP 호출·자동 작업·재시도·웹 프록시를 구현하지 않았고, 이 코드로 발생하는 OpenAI 요청과 과금은 0입니다. 키를 넣거나 `OPENAI_ENABLED=true`로 바꾸어도 실제 기능이 켜지지 않습니다.

## 비밀키와 설정

OpenAI 공식 문서는 API 키를 브라우저나 앱 같은 클라이언트 코드에 노출하지 말고 서버 환경변수 또는 키 관리 서비스에서 읽도록 안내합니다. [공식 OpenAI 문서 — Authentication](https://developers.openai.com/api/reference/overview#authentication)

실제 키는 서버의 환경변수/secret manager로만 공급하세요. 저장소에 커밋하거나 채팅·로그·URL·스크린샷·`VITE_*` 변수·프런트 번들에 넣지 마세요. `.env.example`은 빈 설정 예시이고 실제 `.env`는 이 작업에서 수정하지 않았습니다.

| 서버 설정 | 기본값 | 향후 유효 범위 |
| --- | --- | --- |
| `OPENAI_ENABLED` | `false` | 준비 플래그일 뿐 실제 호출 불가 |
| `OPENAI_API_KEY` | 비어 있음 | 서버 비밀값, 클라이언트 전달 금지 |
| `OPENAI_MODEL` | 비어 있음 | 허용 목록에 포함된 모델 ID 1개 |
| `OPENAI_ALLOWED_MODELS` | 비어 있음 | 쉼표 구분 서버 허용 목록, 최대 8개 |
| `OPENAI_MAX_INPUT_CHARACTERS` | `8000` | 1~16000 문자 |
| `OPENAI_MAX_OUTPUT_TOKENS` | `512` | 1~2048 토큰 |
| `OPENAI_TIMEOUT_MS` | `5000` | 1000~10000 ms |

모델은 의도적으로 미선택 상태입니다. 실제 모델의 이용 가능 여부·요금·용도와 비용 한도를 확인하고 별도 승인한 뒤 선택해야 합니다. 임의 URL·모델·키를 웹 요청으로 전달받는 기능은 없습니다. 위 한도는 미래 구현을 위한 설정 계약이며, 현재 어떤 입력도 외부로 전송하지 않습니다.

## 현재 보안 경계

- 내부 `OpenAiGateway`의 구현은 항상 고정된 사용 불가 예외로 끝납니다. 입력과 키를 예외·`toString`·응답에 넣지 않습니다.
- 비활성, 설정 불완전/범위 초과, 아직 미구현 상태를 구분하지만 비밀 설정 원문은 오류에 포함하지 않습니다.
- `/api/openai`, `/api/openai/**`, `/api/ai`, `/api/ai/**`는 익명·일반 사용자·관리자 모두 차단합니다. 대소문자와 쿼리 유무로 우회할 수 없습니다. 비정규·위험 인코딩 경로는 기존 Spring Security 방화벽 정책을 유지합니다.
- 컨트롤러·범용 프롬프트 실행 API·임의 모델/외부 URL 프록시는 없습니다. 다른 로그인·공개 API 규칙은 바꾸지 않습니다.
- 전용 Docker 워커와 `run.sh`의 로컬 채점 워커에는 키를 비우고 비활성 CLI 설정을 강제합니다. 채점 코드/격리 실행에 OpenAI 키를 전달하지 않습니다.

## 실제 연결 전 별도 승인할 사항

실제 기능은 나중에 별도 작업으로 구현해야 합니다. 구현 전에 승인된 단일 용도와 역할별 권한, 사용자별/서버 전체 사용량 쿼터, 동시 실행 제한, 비용 한도·승인 절차, 감사 로그의 민감정보 제거, 타임아웃·재시도·장애 격리 정책을 정해야 합니다. 관리자 권한만으로 무제한 사용하게 만들면 안 됩니다.

저장된 문제의 비공개 본문·정답 코드·비공개 테스트케이스·개인정보·사용자 제출 코드를 외부 서비스로 보내지 마세요. 필요하다면 데이터 소유자의 명시적 승인, 목적 제한과 최소화, 비식별화 및 보존 정책 검토를 먼저 거쳐야 합니다. 현재 준비 코드는 이 자료에 접근하거나 전송하지 않습니다.

## 로컬 검증

테스트는 실제 키 없이 가짜 키만 사용합니다. 단위 테스트는 기본 비활성·잘못된 설정·완전한 설정 모두 호출 불가임과 키가 출력되지 않음을 확인합니다. 실제 보안 필터가 적용된 MockMvc 테스트는 익명·일반·관리자 역할의 예약 경로 접근을 거절하고, 공개 경로와 일반 인증 경계는 유지하는지 확인합니다. 실제 OpenAI 네트워크 요청은 하지 않습니다.
